# Patient List

A patient management application built with Angular.
Allows adding, editing, deleting and searching patients. Data is stored in Local Storage.

## Features
- Patient list with name, diagnosis and age
- Add new patient
- Edit patient data
- Delete patient
- Search patients

## Technologies
- Angular
- TypeScript
- Tailwind CSS
- PrimeNG
- Local Storage

## Run locally
1. Clone the repository
   git clone https://github.com/aleksandranikolic96/patient-app.git
2. Install dependencies
   npm install
3. Start the development server
   ng serve
4. Open http://localhost:4200 in your browser
